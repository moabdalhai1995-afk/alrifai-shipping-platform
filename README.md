# منصة الرفاعي للشحن الدولي — V3

هذه نسخة بداية التحويل من MVP إلى منصة فعلية.

## تم تنفيذ المرحلة 1
- Node.js + Express
- قاعدة بيانات SQLite
- إنشاء حساب عميل
- تسجيل الدخول/الخروج عبر جلسة
- إنشاء الطلبات وحفظها في قاعدة البيانات
- أرقام طلبات حقيقية
- تتبع الطلب من قاعدة البيانات
- حفظ طلبات الشراكة في قاعدة البيانات
- API مهيأ للتوسع
- نقطة إدارة أولية للطلبات

## التشغيل
يتطلب Node.js 18+.

```bash
npm install
npm start
```

ثم افتح:
http://localhost:3000

## إنشاء مدير تجريبي (اختياري)
على بيئة اختبار فقط:
```bash
ENABLE_SEED_ADMIN=1 node server.js
```
ثم يمكن استدعاء:
`/api/admin/seed`

بيانات المدير التجريبي:
- الجوال: 0500000000
- كلمة المرور: Admin123!

غيّر SESSION_SECRET وبيانات المدير قبل أي استخدام حقيقي.
