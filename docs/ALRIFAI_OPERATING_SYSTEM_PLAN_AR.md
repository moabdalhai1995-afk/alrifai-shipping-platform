# نظام تشغيل الرفاعي — المخطط التنفيذي

## الهدف
تحويل منصة الرفاعي الحالية إلى نظام تشغيل مركزي واحد يربط واجهة العميل، الشحن، المستودع، الرحلات، التتبع، المتجر، الموردين، الحسابات، الإشعارات، وصلاحيات الموظفين.

## الوحدات الرئيسية
1. لوحة المدير التنفيذية
2. العملاء والحسابات
3. الطلبات وعروض الأسعار
4. الشحنات والتتبع
5. المستودع والباركود
6. الرحلات والحاويات
7. التسليم في السودان
8. المتجر والمنتجات
9. الموردون والمشتريات
10. المدفوعات والفواتير
11. الحسابات والتكاليف والربحية
12. الموظفون والصلاحيات وسجل التدقيق
13. المهام التشغيلية
14. مركز الإشعارات وواتساب
15. مركز تحكم ذكي للمشغل/المدير

## سير الشحنة القياسي
طلب العميل → عرض السعر → تأكيد الطلب/الدفع → استلام في الرياض → إصدار باركود لكل قطعة → إدخال المستودع → التعبئة → ربط الرحلة → التحميل → المغادرة → في الطريق → الوصول للسودان → التخليص → مستودع السودان → خرج للتوصيل → التسليم → إغلاق الشحنة وتسجيل التكلفة والإيراد والربح.

## قاعدة التشغيل
- لكل شحنة رقم تتبع رئيسي.
- لكل قطعة باركود مستقل مربوط برقم الشحنة.
- لا يسمح بإدخال قطعة للمستودع بدون باركود.
- مسح الباركود يغيّر حالة القطعة ويسجل الوقت والموقع والموظف.
- أي تغيير تشغيلي مهم يسجل في سجل تدقيق.
- الصلاحيات حسب الدور.
- البيانات التشغيلية تحفظ في قاعدة بيانات دائمة.
- الموقع والتطبيق يستهلكان نفس الـ APIs والبيانات، ولا توجد إدارة منفصلة لكل واجهة.

- Operations Manager
- Warehouse
- Customer Service
- Sales
- Finance
- Sudan Operations
- Driver/Delivery
- Customer

## المرحلة الأولى
- تثبيت لوحة تشغيل موحدة.
- توحيد الشحنات والرحلات والباركود والتتبع.
- ربط المتجر والطلبات بالشحن.
- تحسين صلاحيات الموظفين.
- توحيد الإشعارات.
- إضافة مؤشرات يومية: الطلبات، الشحنات، القطع، الرحلات، الإيرادات، التكاليف، الربح، الشحنات المتعثرة.

## المرحلة الثانية
- الموردون والمشتريات.
- عروض الأسعار والفواتير.
- المحاسبة التشغيلية.
- تقارير الربحية لكل رحلة/شحنة/عميل.
- استيراد Excel/CSV للموردين والمنتجات.

## المرحلة الثالثة
- مركز المشغل الذكي.
- اقتراح المهام والتنبيهات.
- اكتشاف الشحنات المتأخرة.
- تقارير الإدارة.
- تكاملات الدفع والإشعارات حسب الاعتماد النهائي.

## مبدأ التنفيذ
لا نعيد بناء المنصة من الصفر. نستخدم الكود وقاعدة البيانات والوحدات الموجودة، ونوحّدها تدريجياً مع الحفاظ على بيانات العملاء والطلبات الحالية.
